Modifica le 2 Offerte del Mese

1 promozione valida per i 3 saloni (o un sottoinsieme) + 1 promozione dedicata al Barber Shop.

Come aggiornare le promozioni
  1. Modifica i campi delle due sezioni qui sotto (titoli, prezzi, date...)
  2. Seleziona quali saloni includere nella Promo 3 Sedi (selezionati = promo disponibile in quella sede)
  3. Compila la sezione "Configurazione WhatsApp": per la Promo Multi-Sede inserisci i 3 numeri diversi (Villanova / Villafontana / Imola) + il messaggio predefinito. Per il Barber usa un singolo numero diretto.
  4. Clicca Scarica promo.json per scaricare il file aggiornato
  5. Carica via FTP / Pannello Hosting il file nella cartella app/content/ sostituendo quello vecchio
  6. Per le immagini: carica prima la foto via FTP (es. in app/galleria/), poi inserisci il percorso qui (es. galleria/nuova-foto.jpg)
